# Wiadomość dla testerów

Hej! Udostępniam lokalną wersję testerską TriRise dla Windows.

TriRise to prywatne, local-first centrum Finansów, Formy i Diety. Na tym etapie proszę przede wszystkim o sprawdzenie instalacji, ikony i nazwy skrótu, uruchomienia, nawigacji PL/EN oraz tego, czy wszystkie grafiki ładują się poprawnie.

Nie dodawaj prawdziwych danych finansowych ani prywatnych backupów, jeśli nie testujesz świadomie tych funkcji. Jeśli pojawi się błąd, podeślij screenshot oraz krótki opis wykonanych kroków.
