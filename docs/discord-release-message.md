# Wiadomość dla testerów

Hej! Udostępniam lokalną wersję alpha TriRise dla Windows.

TriRise to prywatne, local-first centrum Finansów, Formy i Diety. Instalator powinien pokazywać branding TriRise. Proszę przede wszystkim o sprawdzenie, czy przyciski instalatora są widoczne, ikona jest poprawna, nie pojawia się nazwa PortfelPilot, aplikacja uruchamia się po instalacji i wszystkie grafiki ładują się poprawnie.

Nie dodawaj prawdziwych danych finansowych ani prywatnych backupów, jeśli nie testujesz świadomie tych funkcji. Jeśli pojawi się błąd, podeślij screenshot oraz krótki opis wykonanych kroków.
