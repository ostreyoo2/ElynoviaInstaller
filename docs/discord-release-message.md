# Wiadomość dla testerów

Hej! Udostępniam testową wersję Elynovia dla Windows.

Elynovia to prywatne, local-first centrum Finansów, Formy i Diety. Proszę sprawdzić nazwę i ikonę Elynovia, czytelność instalatora, uruchomienie aplikacji, automatyczną aktualizację oraz zachowanie lokalnych danych.

Nie dodawaj prawdziwych danych finansowych ani prywatnych backupów, jeśli nie testujesz świadomie tych funkcji. Przy błędzie prześlij screenshot i krótki opis kroków.
