# Elynovia Installer Branding Plan

Celem jest spójny wygląd Elynovia bez zastępowania standardowych kontrolek NSIS. Brandowane są ikony, header 150×57, sidebar 164×314 oraz nazwa produktu.

Aktywne pliki to `branding/installer/elynovia-installer-header.bmp`, `branding/installer/elynovia-installer-sidebar.bmp` i `branding/icons/icon.ico`.

Nie kolorujemy ręcznie systemowych przycisków ani nie zastępujemy całego szablonu `.nsi`. Każda zmiana instalatora wymaga testu instalacji, aktualizacji i deinstalacji na Windows 10/11.
