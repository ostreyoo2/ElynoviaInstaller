# Tauri NSIS Config Recommendations

Aktywna konfiguracja Elynovia używa aktualnych bitmap NSIS i ikon, trybu `currentUser`, języka `English` oraz hooka skrótów Elynovia.

Hook usuwa starsze skróty PortfelPilot i TriRise, a następnie tworzy skróty Elynovia. Nazwy legacy występują tam wyłącznie dla zgodności.

Zmiany instalatora wymagają podpisanego buildu oraz ręcznego testu instalacji, aktualizacji i deinstalacji.
