# NSIS

Główny instalator jest generowany przez Tauri 2 w repo aplikacji. Ten katalog przechowuje dokumentację i ewentualne bezpieczne dodatki instalatora, ale nie zastępuje procesu `npm.cmd run tauri build`.

Przed podpięciem nowych hooków lub bitmap wymagany jest ręczny test instalacji, aktualizacji i deinstalacji na Windows.
